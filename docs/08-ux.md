# 08 — UI/UX Specification: Screen-by-Screen

## Design Principles

1. **Agent-first**: The interface centers on the agent's activity, not listings or browse grids.
2. **Minimal input required**: Every screen should require the minimum possible user action.
3. **Plain language only**: No jargon, no marketplace-specific terminology.
4. **Trust visibility**: Safety indicators are always visible, never hidden.
5. **Mobile-first**: Designed for the phone; web is secondary.

---

## Design System

**Typography**: Inter (body), Sora (headings) — clean, modern, accessible
**Colors**:
- Primary: `#2563EB` (confident blue — trust, action)
- Success: `#16A34A` (money, deals closed)
- Warning: `#D97706` (attention needed)
- Danger: `#DC2626` (fraud alerts, errors)
- Background: `#F8FAFC` (off-white, easy on eyes)
- Card: `#FFFFFF` with `2px solid #E2E8F0`

**Border radius**: 12px for cards, 8px for buttons, 24px for pills
**Spacing**: 8px grid system

## Accessibility Requirements

- **Font size**: Minimum 16px body text; agent summaries at 18px
- **Color contrast**: WCAG AA minimum (4.5:1 for text)
- **Voice input**: All key actions available via voice ("Hey AgentBay, sell my bike")
- **Screen reader**: All images have descriptive alt text; all interactive elements labeled
- **Large text mode**: UI scales gracefully to 200% text size
- **Low-tech mode**: Simplified UI option with larger buttons, less information density
